## Что это такое?

**OSIP-DEFEND** — приложение на Python и PySide6, которое объединяет инструменты проверки файлов и настройки Windows в одном интерфейсе.

Локальный сканер вычисляет SHA-256 и проверяет простые эвристики, мониторинг сообщает о новых файлах в выбранных папках, а вкладка **«Антивирус OSIP»** позволяет последовательно запускать Microsoft Defender и сканер Open-CWS / ClamAV.

Исходный код приложения находится в одном файле — **`osip_defend.py`**. Настройки, журналы и резервные копии создаются отдельно при использовании.

> [!IMPORTANT]
> OSIP-DEFEND — утилита с демонстрационным локальным движком и адаптерами сторонних сканеров, а не сертифицированная замена штатной защите Windows. Отсутствие находок не гарантирует безопасность файла.

## ✨ Возможности

| Раздел | Что умеет |
| :--- | :--- |
| **Сканер** | Выбор папки, SHA-256, восемь безопасных тестовых сигнатур, эвристика, прогресс, журнал и остановка проверки. |
| **Защита** | Рекурсивное наблюдение за созданием и перемещением файлов с выбранными расширениями через `watchdog`. |
| **Система** | Снятие отдельных ограничений Диспетчера задач, Редактора реестра и Панели управления; включение отображения скрытых файлов. |
| **Журнал** | Локальная история действий, очистка событий и круговая диаграмма последней локальной проверки. |
| **Антивирус OSIP** | Запуск одного или двух внешних движков с отдельными результатами и общим выводом. |
| **Настройки** | Профили проверки, исключения, параметры мониторинга, лимиты Open-CWS, оформление и размер журнала. |

### Интерфейс

- Тёмная палитра с зелёным акцентом.
- Боковая навигация и встроенные векторные иконки.
- Карточки статистики и понятные статусы задач.
- Настраиваемый размер основного текста и отключаемые анимации.
- Фоновое выполнение проверок без блокировки основного интерфейса.

## 🚀 Быстрый старт

### Требования

- **Windows 10 или Windows 11**.
- **Python 3.10 или новее**.
- Библиотеки `PySide6`, `watchdog`, `psutil`.
- Установленный Microsoft Defender — для профиля **OSIP System**.
- Отдельно установленный Open-CWS / ClamAV с базой сигнатур — для профиля **OSIP Community**.

Внешние движки и их базы **не входят** в Python-файл. Локальный сканер, мониторинг и системные инструменты не требуют установки Open-CWS.

### Установка и запуск

Скачайте `osip_defend.py`, откройте PowerShell в папке с файлом и выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install PySide6 watchdog psutil
.\.venv\Scripts\python.exe osip_defend.py
```

Активировать виртуальное окружение отдельно не нужно.

> [!NOTE]
> Приложение не повышает права автоматически. Для изменения параметров `HKLM` и некоторых операций Microsoft Defender могут потребоваться права администратора. На управляемом компьютере соблюдайте политики организации.

## 🔍 Как пользоваться

### 1. Проверка папки локальным сканером

1. Откройте **«Сканер»**.
2. Нажмите **«Обзор»** и выберите папку.
3. Нажмите **«Начать сканирование»**.
4. Следите за прогрессом, журналом и таблицей результатов.
5. При необходимости нажмите **«Остановить»**.

**Как читать результаты:**

- **Тестовая сигнатура** — точное совпадение с одним из восьми безвредных демонстрационных образцов.
- **Подозрительный** — сработала эвристика, например обнаружен недавно созданный `svchost.exe` в папке `Temp`. Это не доказательство заражения.
- **Ошибка / пропуск** — файл не удалось прочитать либо он исключён настройками. Такой файл нельзя считать проверенным.

Кнопка **«Удалить найденное»** удаляет только файлы с подтверждённой **тестовой сигнатурой**, а не эвристические находки и не результаты внешних движков. Перед удалением повторно проверяется SHA-256 и запрашивается подтверждение.

> [!WARNING]
> Удаление необратимо: корзина не используется. Операция затрагивает все оставшиеся тестовые образцы в списке, а не только выделенную строку.

### 2. Мониторинг папок

1. Откройте **«Защита»**.
2. Нажмите **«Включить реальную защиту»**.
3. Проверьте список фактически наблюдаемых папок.
4. Новые события появятся в журнале.

По умолчанию отслеживаются новые и перемещённые `.exe` и `.bat` в:

```text
%WINDIR%\Temp
%PUBLIC%
%TEMP%
```

Папки, расширения и задержка обработки меняются в **«Настройки → Мониторинг»**.

**Это наблюдатель, а не блокировщик:** он не запрещает запуск программ, не анализирует содержимое файлов и ничего автоматически не удаляет. Изменение содержимого уже существующего файла само по себе не является отслеживаемым событием.

### 3. Системные инструменты

Во вкладке **«Система»** выберите нужную операцию и подтвердите изменение реестра:

- Разблокировать Диспетчер задач.
- Разблокировать Редактор реестра.
- Разблокировать Панель управления.
- Показать скрытые файлы, включая защищённые системные файлы в Проводнике.

Перед изменением исходные значения сохраняются в `registry-backup.jsonl`. Резервная копия предназначена для ручного восстановления; отдельного автоматического восстановления в интерфейсе нет.

Операции не перезапускают Проводник и не обходят корпоративные политики. Для отображения скрытых файлов может понадобиться открыть новое окно Проводника.

## 🧩 Два движка — одна вкладка

Во вкладке **«Антивирус OSIP»** доступны три профиля:

| Профиль | Как работает |
| :--- | :--- |
| **Оба движка** | Последовательно запускает Microsoft Defender, затем Open-CWS / ClamAV. |
| **OSIP System** | Использует установленный Microsoft Defender через `MpCmdRun.exe`. |
| **OSIP Community** | Использует настроенный сканер Open-CWS / ClamAV. |

Названия OSIP System и OSIP Community — обозначения профилей интерфейса. Сторонние движки не выдаются за собственную разработку OSIP; сведения об их происхождении доступны в приложении.

### OSIP System · Microsoft Defender

- `MpCmdRun.exe` ищется в стандартных каталогах Windows.
- Перед запуском проверяется действующая цифровая подпись Microsoft через Authenticode.
- Используется выборочная проверка папки с `-DisableRemediation`.
- Кнопка **«Обновить базу Windows»** запускает штатное обновление сигнатур Defender.
- Настройки и службы фоновой защиты не отключаются и не переименовываются.

**Код `2` не означает однозначно найденный вирус:** он также может указывать на ошибку сканирования или необходимость действия пользователя. Всегда читайте исходный вывод.

В режиме `-DisableRemediation` результаты этой проверки выводятся в консоль движка и не добавляются как обнаружения в историю защиты Windows. Независимая фоновая защита продолжает действовать по своим правилам.

### OSIP Community · Open-CWS / ClamAV

> [!WARNING]
> [Open-CWS Anti-virus](https://github.com/mrkaban/Open-CWS-Anti-virus) больше не поддерживается автором. Старый движок может быть несовместим с актуальными базами. Для адаптера также поддерживается отдельно установленный `clamscan.exe`.

**Подключение:**

1. Установите доверенный пакет Open-CWS / ClamAV отдельно.
2. Откройте **«Настройки → Open-CWS»**.
3. Укажите сканер `MSScmd.exe` либо `clamscan.exe`.
4. Укажите папку с базой сигнатур. Для Open-CWS это обычно `bin\db`.
5. Проверьте источник пакета, отметьте **«Доверяю выбранному пакету…»** и нажмите **«Сохранить настройки»**.
6. Подтвердите разрешение на запуск выбранного файла и его DLL.

Для установленного Open-CWS типовые пути выглядят так:

```text
C:\Open CWS Anti-virus\bin\MSScmd.exe
C:\Open CWS Anti-virus\bin\db
```

Приложение сохраняет SHA-256 выбранного EXE и проверяет его перед запуском. После изменения бинарника требуется заново проверить пакет и подтвердить доверие. **Совпадение хеша не доказывает безопасность программы или её DLL.**

Адаптер запускает сканер напрямую, без BAT-скриптов проекта и без параметров завершения процессов, удаления или перемещения файлов. Обновление баз Community выполняется отдельно: кнопка обновления в общей вкладке относится только к Microsoft Defender.

| Код Open-CWS / ClamAV | Значение |
| :---: | :--- |
| `0` | Совпадений не обнаружено в пределах возможностей и лимитов движка. |
| `1` | Обнаружены совпадения; файлы не изменены адаптером. |
| `2` и другие ошибки | Проверка завершилась с ошибкой; изучите вывод. |

### Важные ограничения общей проверки

- Внешние проверки работают **в режиме отчёта**, без автоматического лечения.
- Исключения локального SHA-256-сканера **не передаются** внешним движкам.
- Параметр рекурсии применяется к локальному сканеру и Community. Microsoft проверяет папку по собственным правилам.
- Отсутствующий движок не считается успешно завершившим проверку.
- **«Прекратить задачу»** останавливает текущий CLI и не запускает следующий движок. Остановка проверки внутри службы Microsoft при этом не гарантируется.
- Лимиты файлов и распаковки могут ограничивать покрытие Community-проверки. Код `0` не означает, что проверен каждый байт каждого файла.

## ⚙️ Гибкие настройки

| Категория | Доступные параметры |
| :--- | :--- |
| **Общие** | Папка по умолчанию, профиль внешних движков, тайм-аут каждого CLI, анимации, размер текста, лимит событий. |
| **Сканер** | Рекурсия, включение эвристики, возраст «недавнего» файла, glob-исключения. |
| **Мониторинг** | Список папок, расширения файлов и задержка события. |
| **Open-CWS** | Путь к EXE и базе, доверенный SHA-256, проверка архивов, лимиты размера файла и распаковки. |
| **Сведения** | Происхождение движков, ссылки на документацию и ограничения проверки. |

Пример исключений для **локального** сканера — по одному шаблону на строку:

```text
*.iso
node_modules
cache/*
```

Шаблоны сопоставляются с именем или относительным путём без учёта регистра.

Оформление и размер журнала применяются сразу. Запущенные задачи используют снимок своих настроек; новые параметры проверки и мониторинга применятся при следующем запуске задачи. Активный наблюдатель автоматически не перезапускается.

## 🧪 Безопасная демонстрация

Для знакомства с локальным сканером не нужны настоящие вредоносные файлы.

**Через интерфейс:** нажмите **«Создать тесты»**, выберите папку и запустите проверку созданных образцов.

**Через командную строку:**

```powershell
.\.venv\Scripts\python.exe osip_defend.py --create-demo .\OSIP-demo
.\.venv\Scripts\python.exe osip_defend.py --self-test
```

Первая команда создаёт восемь безвредных текстовых образцов. Их сигнатуры относятся только к демонстрационной базе OSIP: сторонние антивирусы не обязаны считать эти файлы угрозами.

`--self-test` проверяет базовую логику локального движка, а не полноценную работоспособность всех внешних компонентов. Для повторного создания демонстрации выберите новую папку: существующие файлы не перезаписываются.

## 📁 Где хранятся данные

```text
%LOCALAPPDATA%\OSIP-DEFEND\
├── settings.json          # Настройки приложения
├── events.json            # Общая история событий
├── registry-backup.jsonl  # Исходные значения изменяемых параметров реестра
├── defender-*.log         # Исходный вывод Microsoft Defender
└── cws-*.log              # Исходный вывод Open-CWS / ClamAV
```

Файлы создаются по мере использования соответствующих функций.

- Кнопка **«Очистить логи»** очищает общий журнал событий, но не удаляет резервные копии реестра и отдельные исходные логи движков.
- Лимит событий ограничивает общий журнал, а не количество отдельных файлов `defender-*.log` и `cws-*.log`.
- Журналы могут содержать пути к файлам. Проверяйте их перед публикацией в issue.

## 🔐 Приватность и безопасность

- Локальный сканер и наблюдатель не отправляют файлы на серверы OSIP.
- Приложение не отключает Microsoft Defender и не меняет его облачные политики.
- Defender может использовать сетевые и облачные функции согласно настройкам Windows. Обновление сигнатур требует доступа к настроенным источникам.
- Изменения реестра требуют отдельного подтверждения.
- Сторонние бинарники не скачиваются, не устанавливаются и не запускаются автоматически.
- Демонстрационная база не предназначена для обнаружения современных вредоносных программ.

## 🛠️ Если что-то не работает

| Проблема | Что проверить |
| :--- | :--- |
| Не найден `PySide6`, `watchdog` или `psutil` | Устанавливайте зависимости тем же интерпретатором, которым запускаете приложение. |
| OSIP System недоступен | Наличие Microsoft Defender, состояние службы, доступ к стандартным каталогам и политики Windows. |
| Не проходит проверка подписи | Не отключайте проверку. Проверьте целостность Windows, доступ к PowerShell и политики организации. |
| OSIP Community недоступен | Путь к сканеру, наличие базы, сохранённое доверие и совпадение SHA-256. |
| Community сообщает об ошибке базы | Актуальность и совместимость движка с сигнатурами. Старый Open-CWS может не поддерживать современные базы. |
| Изменена только часть параметров реестра | Права на `HKLM`, политики организации и подробности в журнале. |
| Нет событий наблюдения | Фактически наблюдаемые папки, расширения и тип события: создание или перемещение. |

## Статус проекта

GUI, локальный движок и обработка CLI-адаптеров проверялись в Linux с безопасными тестовыми процессами.

**Реальные внешние Windows-движки, операции реестра и совместимость Open-CWS с конкретными базами в этой среде не проверялись.** Перед использованием на рабочем компьютере протестируйте приложение в отдельной Windows-среде и сделайте резервные копии важных данных.

## Сторонние компоненты

- [PySide6 / Qt for Python](https://doc.qt.io/qtforpython-6/) — графический интерфейс.
- [watchdog](https://github.com/gorakhargosh/watchdog) — события файловой системы.
- [psutil](https://github.com/giampaolo/psutil) — сведения о процессах и службах.
- [Microsoft Defender](https://learn.microsoft.com/en-us/defender-endpoint/command-line-arguments-microsoft-defender-antivirus) — внешний системный движок Microsoft.
- [Open-CWS Anti-virus](https://github.com/mrkaban/Open-CWS-Anti-virus) — проект mrkaban, GPL-2.0; больше не поддерживается.
- [ClamAV](https://www.clamav.net/) — движок, используемый Community-адаптером.

Названия и права на сторонние компоненты принадлежат их владельцам. Их бинарники не входят в `osip_defend.py`; при отдельном распространении соблюдайте соответствующие лицензии.
